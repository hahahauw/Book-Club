Set up cover uploads

Pick one free image host below — this only takes a couple minutes, and your keys stay on this device.

Best if you want room to grow — a generous free tier built for exactly this.

  1. Go to cloudinary.com and sign up (free, no card needed)
  2. On your Dashboard, copy your Cloud name
  3. Go to Settings → Upload → Upload presets → Add upload preset
  4. Name it bookclub_unsigned and set Signing Mode to Unsigned
  5. Paste your cloud name below

Fastest to set up — one API key, no preset configuration.

  1. Go to api.imgbb.com and sign up (free)
  2. Copy the API key it gives you
  3. Paste it below

Your credentials are stored only in this browser's local storage — never sent anywhere but the image host you chose. You can change or clear them anytime from the ⚙ button.
